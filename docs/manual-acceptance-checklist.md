# 手动验收清单

本清单只用于真实集群发布前的人工冒烟检查。自动验收必须在不访问真实服务器的情况下通过。

## 准备

- [ ] 安装离线包中的 `simple-sftp-<version>.vsix` 和 `simple-experiment-<version>.vsix`。
- [ ] 打开一个包含 1 个 Hub 和至少 1 个 Worker 配置的工作区。
- [ ] 如果工作区已有重要运行状态，先备份 `simple_cluster/`。

## 启动与 Webview

- [ ] 执行 `SimpleExperiment：打开面板`。
- [ ] 确认面板正常加载，不出现空白页。
- [ ] 执行集群自检入口。
- [ ] 确认告警可操作，输出中没有 token、密码或完整私钥路径。

## Xshell 隧道、Agent 与 Runtime

- [ ] 检查 Hub runtime 版本。
- [ ] 部署 runtime 到 Hub 与 Worker。
- [ ] 启动或重连 Hub Agent 实时流。
- [ ] 确认实时更新来自 Agent 流，不来自高频轮询或 direct SSH 回退。
- [ ] 手动停止 Agent 后，确认重启和重连流程可用。
- [ ] 临时将一个 Worker 标记为不可用，确认其他 Worker 仍能刷新。

## 计划与运行

- [ ] 对不超过 10 个实验的小计划执行 dry-run。
- [ ] 确认生成的计划写入计划注册表。
- [ ] 确认 dry-run 显示实验数量和重复项告警。
- [ ] 启动一个小计划。
- [ ] 确认生命周期行能经过 queued、running、completed 或 failed。
- [ ] 对一个失败实验执行重试。

## 同步、归档、删除

- [ ] 同步代码到 Hub。
- [ ] 归档一个已完成实验。
- [ ] 确认 Local、Hub、Worker 的归档终态一致。
- [ ] 删除一个测试产物。
- [ ] 确认 tombstone 能阻止该产物刷新后重新出现。
- [ ] 如果任一端点失败，确认残留文件和失败原因可见。

## 结果与论文流程

- [ ] 解析一个 `metrics_summary.csv`。
- [ ] 对一个实验目录运行输出契约检查。
- [ ] 导出输出能力矩阵。
- [ ] 导出论文表格。
- [ ] 导出小规模报告。
- [ ] 冻结论文结果。
- [ ] 重新解析或添加一个结果，确认当前结果与冻结结果的差异可见。

## 对比与统计

- [ ] 创建一个包含 baseline 和 ours 的对比研究。
- [ ] 生成对比计划 dry-run。
- [ ] 运行公平性检查。
- [ ] 导出对比报告。
- [ ] 确认论文手动结果与本地解析结果分开标记。
- [ ] 解析新结果后，确认统计标记会刷新。

## Case 级检查

- [ ] 如果存在 `metrics_case.csv`，执行 case 级解析。
- [ ] 运行最差样本或错误样本分析。
- [ ] 运行亚组分析。
- [ ] 运行泄漏检查。
- [ ] 缺少 `patient_id` 时，应显示“无法做病人级泄漏检查”，不能显示为通过。

## 通过标准

- [ ] Webview 不空白。
- [ ] 没有未处理异常通知。
- [ ] 已删除产物不会重新出现。
- [ ] 冻结论文表格不会静默变化。
- [ ] 告警持续可见，不会被显示成通过。
- [ ] `npm run acceptance` 生成的验收报告已纳入发布记录。
